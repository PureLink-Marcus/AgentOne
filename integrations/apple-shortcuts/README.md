# AgentOne Apple Shortcuts

`guenni-light-off.json` ist eine secret-freie Bauvorlage, keine direkt importierbare oder signierte Apple-Shortcut-Datei. Apple Kurzbefehle wird anhand von `docs/SIRI-GUENNI-SHORTCUTS.md` auf dem iPhone eingerichtet. Den persönlichen Key ausschließlich aus der lokalen, gitignorierten Private-Access-Ablage übernehmen.
